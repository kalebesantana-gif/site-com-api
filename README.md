# 🌡️ Clima Agora

Site de consulta de temperatura atual utilizando a API Open-Meteo.

## Tecnologias

- HTML5
- CSS3
- JavaScript
- Open-Meteo API

## Como executar

1. Abra a pasta no VS Code.
2. Abra o arquivo `index.html` no navegador.
3. Digite uma cidade.
4. Clique em **Pesquisar**.

Não é necessário instalar dependências ou configurar uma chave de API.

## Publicar no GitHub Pages

Envie `index.html`, `style.css`, `script.js` e `README.md` para um repositório do GitHub.

Depois vá em:

**Settings → Pages → Deploy from a branch → main → / (root) → Save**

Aguarde o GitHub publicar o site.
